## 03 장면 메모

- 03 장면은 게임이 스프라이트 속성 테이블(SAT)을 매 프레임 직접 다시 써서 자막이 덮이는 문제가 있었고, 게임이 VDC 레지스터 R13을 확정하는 지점 바로 앞에 자막을 쓰도록 끼워 넣어 해결했습니다(자세한 방법은 `docs/07_시네마자막.md` 계열 문서에 정리할 예정).
- 자막을 하단 장식 띠 위로 16px 올려 보는 시험은 글자 일부가 사라져(스프라이트가 화면 줄마다 그려지는 개수 제한 때문으로 보입니다) 채택하지 않았습니다.
