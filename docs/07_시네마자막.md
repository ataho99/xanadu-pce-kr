# 07. 시네마 자막

원판의 애니메이션 장면(시네마)은 성우의 목소리만으로 흘러가고, 자막이 없습니다. 한글판에서는 이 장면들에 한국어 자막을 새로 얹었습니다.

## 스프라이트로 그리기

시네마는 대사창을 쓰지 않습니다. 그래서 하드웨어 스프라이트로 글자를 직접 그려 영상 위에 띄우는 장치를 새로 만들었습니다.

- 12×12 글꼴을 16×16 스프라이트 안에 2×2 타일로 나눠 그립니다.
- PC엔진은 16×16 스프라이트의 패턴 번호 마지막 비트를 무시합니다. 그래서 글자 모양은 짝수 번호 경계에만 둡니다.
- 한 가로줄에 스프라이트를 16개까지만 그릴 수 있어서, 자막은 한 줄 16글자 이내로 씁니다. 두 줄 자막은 프롤로그 장면에서 쓸 수 있는 영상 메모리가 연속 48타일뿐이라 물리적으로 불가능함을 확인해, 한 줄 방식으로 확정했습니다.

## 타이밍

자막이 뜨고 지는 시점은 원본 음성을 분석해 실제로 말소리가 나는 구간에 맞췄습니다. 말이 시작되고 0.5초 뒤에 나타나서, 말이 끝나고 0.2초 뒤에 사라집니다. 실측한 표시 지연은 평균 0.528초, 표준편차 0.012초였습니다.

## 영상을 깨뜨리지 않기

- 게임이 영상을 압축 해제하는 영역에 데이터를 두면 장면이 깨집니다. 「디스크에서 0인 곳은 비어 있다」는 가정이 틀렸다는 것을 알게 된 뒤로는, 개발 중에 게임이 실제로 읽는 위치를 돌려 가며 측정하고, 읽지 않는 자리에만 자막 데이터를 둡니다.
- 화면 갱신 인터럽트가 제자리로 돌아오는지 감시하는 장치를 넣었습니다. 실기에서의 인터럽트 동작은 아직 확인하지 못했습니다.
