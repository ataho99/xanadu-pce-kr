# 풍의 전설 자나두 (PC엔진 CD) 한글패치

『風の伝説ザナドゥ』(Kaze no Densetsu Xanadu, PC Engine Super CD-ROM², 1994)의 한글패치와 분석 노트입니다.

> 진행 중. 패치는 아직 공개 전입니다.

## 이 저장소에 있는 것

- `docs/`: 분석 노트. 디스크 구조, 압축 방식, 블록과 청크 구조, 메모리 배치, 대사 렌더러 분석을 담습니다.
- `tools/`: 분석과 빌드에 쓴 도구.
- 릴리스: 한글패치(xdelta)는 공개 시점에 Releases에 올립니다.

## 이 저장소에 없는 것

- 게임 이미지(bin/cue/iso)나 거기서 뽑아낸 데이터와 그래픽
- 일본어 원문 대사와 번역 대사 전문

패치는 각자 가진 원본 이미지에 적용하는 방식입니다. 맞는 원본 이미지의 sha256은 릴리스와 함께 적습니다.

## 진행 상황

- 대사 번역 대부분 적용 완료
- 남은 과제: 띄어쓰기가 빠진 대사 약 1,000줄 복원(블록 확장 방식 조사 중), 실기 확인, 통짜 플레이 확인
