# 바람의 전설 제나두 (PC엔진 CD) 한글패치

『風の伝説ザナドゥ』(Kaze no Densetsu Xanadu, 1994)는 니혼 팔콤이 만들고 허드슨이 PC엔진 슈퍼 CD-ROM²로 낸 액션 RPG입니다. 이 저장소는 그 게임을 한국어로 옮긴 한글패치와, 그 과정에서 밝혀낸 내부 구조를 정리한 기록입니다.

> 아직 작업 중입니다. 패치는 공개 전입니다.

## 왜 이렇게 오래 걸렸나

PC엔진은 1987년에 나온 8비트 게임기입니다. 메모리는 한 줌이고, 게임 데이터는 거의 전부 압축되어 디스크 곳곳에 흩어져 있습니다. 대사는 따로 모여 있지 않고 장면을 움직이는 프로그램 코드 사이사이에 끼어 있습니다. 일본어 문장을 한국어로 바꾸는 순간 길이가 달라지고, 길이가 달라지면 그 뒤의 코드 주소가 전부 어긋납니다.

뜯어볼수록 감탄하게 됩니다. 1994년의 니혼 팔콤과 허드슨 개발진은 손바닥만 한 메모리에 챕터 하나를 통째로 압축해 올려 두고, 필요한 장면만 그때그때 풀어 쓰는 방식으로 하드웨어를 끝까지 짜냈습니다. 바이트 하나도 허투루 쓰지 않은 설계 덕분에, 30년 뒤의 우리도 그 질서를 읽어 낼 수 있었습니다. 이 패치는 그분들의 솜씨에 대한 존경에서 출발합니다.

그래서 이 작업은 번역보다 해부에 가까웠습니다.

- 디스크 목록 표의 형식을 밝혀냈습니다.
- 팔콤 고유의 압축 방식을 풀고, 다시 압축해 넣되 원래 자리보다 커지면 상자를 키우고 뒤를 밀어 주는 도구를 만들었습니다.
- 장면 하나하나를 담은 데이터 상자의 구조와, 그것이 메모리 어느 칸에 어떻게 올라가는지를 확인했습니다.
- 시스템 카드 안의 글꼴 영역을 12픽셀 한글 글꼴로 바꿨습니다.
- 원래 문장보다 긴 번역이 들어갈 수 있도록, 게임 자체에 있던 「다른 위치로 건너가 이어 읽기」 기능을 빌려 남는 자리에 이어 붙였습니다.

## 시네마 자막

이 게임에는 성우가 연기하는 애니메이션 장면(시네마)이 들어 있는데, 원판에는 자막이 없습니다. 목소리만으로 흘러가는 장면에 한국어 자막을 새로 얹었습니다.

- 시네마 화면은 대사창을 쓰지 않으므로, 하드웨어 스프라이트로 자막 글자를 직접 그려 영상 위에 띄우는 장치를 새로 만들었습니다.
- 자막이 뜨고 사라지는 시점은 원본 음성을 분석해 실제로 말소리가 나는 구간에 맞췄습니다. 문장이 시작되면 잠깐 뒤에 나타나고, 말이 끝나면 조금 뒤에 지워집니다.
- 영상을 압축 해제하는 영역을 건드리면 장면이 깨지기 때문에, 개발 중에 게임이 실제로 읽는 위치를 돌려 가며 측정하고, 읽지 않는 자리에만 자막 데이터를 두었습니다.

모든 변경은 에뮬레이터에서 원판과 화면을 한 장씩 비교해 확인했고, 원판과 다른 바이트가 의도한 자리 밖에서 생기지 않았는지 매번 검사했습니다.

## 이 저장소에 없는 것

- 게임 이미지(bin/cue/iso)와 거기서 뽑아낸 데이터, 그래픽
- 일본어 원문 대사와 번역 대사 전문

패치는 각자 가진 원본 이미지에 적용하는 방식입니다. 맞는 원본 이미지의 sha256 값은 릴리스와 함께 적겠습니다.

## 진행 상황

- 대사 번역: 번역 DB의 일본어 대사 8,607줄 가운데 8,577줄을 적용했고, 나머지 가운데 일부를 더 넣었습니다. 남은 대사는 자리 문제로 보류 중입니다.
- 띄어쓰기: 공간이 모자라 띄어쓰기를 줄였던 대사를, 데이터 상자를 키워 이어 붙이는 방법으로 되살리고 있습니다. 지금 패치에는 챕터 0에서 33곳, 나머지 챕터 블록에서 496곳을 되살린 대사가 들어 있습니다. 게임 자신의 압축 해제 코드로 풀어 바이트가 맞는 것까지는 확인했고, 실제 대화 화면은 아직 확인하지 못했습니다.
- 남은 확인: 실기 확인, 처음부터 끝까지 이어서 하는 플레이 확인.
